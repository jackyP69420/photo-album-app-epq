# Wedding Album App - EPQ Project

A photo-sharing iOS app for weddings, built as an A-level Extended Project Qualification (EPQ).

## Project Overview

This project investigates how intuitive UI design and user experience principles can improve engagement and satisfaction in photo-sharing applications. The research and development are documented throughout the build process.

## Technologies

- **Language:** Swift
- **Framework:** SwiftUI
- **IDE:** Xcode
- **Platform:** iOS

## Project Structure

- `WeddingAlbum/` — Xcode project and app code
- `documentation/` — EPQ research and development documentation

## Documentation

- **Literature Review** — Research on UX design, photo-sharing apps, and design principles
- **Development Journal** — Progress notes, challenges, decisions, and reflections
- **Research Notes** — Project research findings and inspiration
- **Reading Log** — Sources and key takeaways

## Features (In Development)

- Photo upload and storage
- Photo sharing and viewing
- User-friendly interface design
- Responsive layout

## Status

Early development
